The problem

Your agents are driving blind.

They were trained on yesterday's world and nobody told them things changed.

001

One source. No verification.

Every agent today fetches from a single endpoint and trusts it completely. No cross-reference. No conflict detection. One bad source = bad decision.

002

Stale training data.

Models answer high-stakes financial questions from data frozen at training cutoff. Gas fees, prices, protocol states — all are live. The model doesn't know.

003

No confidence signal.

Agents answer with the same confidence whether they have 3 corroborating sources or one unreliable one. The user has no way to know the difference.

004

No standard interface.

Every team re-implements their own data fetching, deduplication, and validation. The infrastructure wheel gets reinvented on every project.

How it works

Multi-source. Aggregated. Delivered.

Pulse runs continuously, fetching from independent sources in parallel, resolving conflicts, and serving verified truth via one API call.

Get started

One line. Any agent.

Python SDK, HTTP API, or WebSocket subscription. Works with LangChain, AutoGen, CrewAI, or any custom agent.

# Install
pip install pulse-sdk

# Use
from pulse import feed

ctx = feed.get("gas_price")

# ctx.value → {safe_gwei, fast_gwei, base_fee}
# ctx.confidence → 0.87
# ctx.source_count → 3
# ctx.latency_ms → 342

if ctx.value["safe_gwei"] > 80:
    agent.defer_transaction()
# Gas price — aggregated from 3 sources
curl http://localhost:7070/feed/gas_price

# ETH price with query
curl "http://localhost:7070/feed/crypto_price?q=ETH"

# Force fresh (bypass cache)
curl "http://localhost:7070/feed/gas_price?fresh=true"

# Response shape
{
  "value": { "safe_gwei": 12.5, ... },
  "confidence": 0.87,
  "source_count": 3,
  "agreement_score": 0.94,
  "latency_ms": 342
}
# Clone and run everything
git clone https://github.com/itachi-exe/pulse
cd pulse
docker-compose up

# Pulse is now live on :7070
curl http://localhost:7070/health

# Without Docker (requires Rust + Redis)
redis-server --daemonize yes
cargo run --release
from pulse import feed

# Subscribe — agent receives updates every 10s
def on_gas(ctx):
    print(ctx.summary())
    if ctx.value["safe_gwei"] > 80:
        agent.pause_transactions()

sub = feed.subscribe("gas_price", on_update=on_gas)
sub.start()  # non-blocking
