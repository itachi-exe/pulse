How it works

From question to grounded answer

Pulse intercepts the agent's question, fetches live verified data, and injects it as grounded context before the LLM ever sees it.

01

Agent sends a query

Your agent calls the Pulse API with a natural-language question or structured feed request. No prompt engineering required.

02

Pulse fetches live data

The Rust core fans out to CoinGecko, Etherscan, and other live sources. Redis caches fresh results. Stale data is never served.

03

Confidence scored

Each answer gets a confidence score. If Pulse can't verify the data, it says DEFER — no hallucinated confidence returned.

04

Grounded context returned

Your agent receives a structured JSON block with the fact, confidence, and source. Feed it straight to your LLM.

FAQ

Common questions

What kinds of data does Pulse provide?
Crypto prices (ETH, BTC, SOL), gas estimates, context confidence scores, and the Python SDK. More feeds — news freshness, chain state, time/weather — shipping next.
How is this different from calling CoinGecko directly?
Pulse unifies multiple sources, caches intelligently, scores confidence, and formats the result so your agent gets a single grounded context block — not raw JSON it has to interpret itself.
Does this replace the LLM?
No. Pulse sits in front of the LLM and enriches its context. Your agent still reasons with the model — it just reasons with correct data now.
Is the API free?
Yes, during the hackathon phase. The public endpoint is open. Rate limits apply. Production API keys coming post-demo.
What's the stack?
Rust (Axum + Tokio) for the API, Redis for caching, Python SDK, nginx reverse proxy, pm2. Deployed on a Contabo VPS in Berlin.
